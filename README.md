# Global COVID-19 Analytics Dashboard

## 📌 Project Overview
This project is an interactive data dashboard built in Power BI to analyze global COVID-19 statistics. The goal was to design a modern, grid-style layout (inspired by e-commerce dashboards) to track cases, deaths, recoveries, and population data across different continents.

## 🛠️ Tools Used
* **Power BI Desktop** (Data Visualization, DAX)
* **Microsoft Excel / CSV** (Data Source)

## 📊 Dashboard Features
* **Custom UI:** Bright yellow background with vibrant, bordered KPI cards.
* **Dynamic Slicer:** Filter all visuals instantly by Continent.
* **KPI Cards:** Total Cases, Total Deaths, Total Recovered, and Active Cases.
* **Visualizations:** 
  - Top 10 Countries by Total Cases (Bar Chart)
  - Global Cases by Continent (Donut Chart)
  - Total Deaths by Continent (Treemap)
  - Total Recovered by Continent (Pie Chart)

## 💡 Key Insights
* The dashboard reveals a massive concentration of cases in North America and Asia.
* Recoveries are high, but active cases still remain a significant portion globally.
